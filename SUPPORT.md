# Release Ledger support

Release Ledger is maintained by Sanyam Singh Brar, who publishes as ItsMeSamey.

Use this project's public issue tracker for questions and bug reports. Include the app version, the steps you took, the result you expected, and the result you saw. A small example with invented issue names is useful.

Keep Jira issue content, names, credentials and other private data out of public reports. Replace them with a synthetic example. Reports and replies in the issue tracker are public.

Release Ledger follows visible Jira dependency links. It helps inspect blockers, cycles, missing evidence and hypothetical completions. Check workflow, capacity and acceptance criteria separately.

Support is provided as time permits. Response times are not guaranteed.

Implementation, tests, documentation and review were assisted by OpenAI Codex.
