# Release Ledger terms

For the Jira issue panel. Updated 7 November 2026.

Release Ledger is provided by Sanyam Singh Brar, who publishes as ItsMeSamey. Use the project's public support page for questions.

Use the app only on Jira sites and data that you are allowed to access. A site administrator must authorize installation. Atlassian's service terms and site permissions also apply.

The app presents a bounded snapshot of visible dependency links. It can show cycles, missing evidence and the effect of hypothetical completions. Its current traversal is limited to 60 issue reads and eight dependency levels. A Done status stops further traversal. Hidden links, unreadable issues and later Jira changes can affect the picture.

The output supports a planning discussion. It does not establish a delivery date, task priority, available capacity or acceptance of completed work. Review the source issues and your team's requirements before acting. Scenarios do not write changes to Jira.
